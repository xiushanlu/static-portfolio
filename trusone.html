From Generic to Professional

A visual redesign for an AI-powered EHS & ISO compliance platform—creating a design system and elevating the interface from template-quality to enterprise-ready.

ReactTypeScriptTailwindFigma

The Brief

TrusOne is an AI-driven EHS (Environment, Health & Safety) and ISO compliance platform that helps organizations manage compliance requirements. The platform features TrusAI, an intelligent assistant that provides real-time guidance on regulations, safety protocols, and compliance standards. The existing dashboard was functional but looked generic—like any AI-generated template. I was tasked with making it look professional and clean.

My Role: Software Engineering Intern (Visual Redesign, Design System, Frontend Implementation)

The Problem

The original dashboard worked, but it lacked personality. It looked like a default template—nothing about it said "TrusOne" or felt memorable. For a product selling to enterprise customers, credibility matters.

The Process

Step 1 – Design Exploration

I created three visual directions, each exploring different color treatments and styling approaches. The founder chose the third direction for its clean, professional feel.

Step 2 – Design System

I built a style guide with:

  • Color palette based on the TrusOne brand (blue-to-purple gradient)
  • Typography scale (Lato)
  • Button styles (primary/secondary, all states)
  • Card and component patterns
  • Accessible color combinations
Step 3 – Implementation

I applied the new design system across the existing screens, updating colors, fonts, and styling. The homepage got a layout refresh. I also edited a ReactBits animated background—changing it from sparkling stars to growing and shrinking purple gradient blobs—which appears across all pages to add visual interest.

Reflections

"Reskinning" sounds simple, but creating a cohesive design system that elevates every screen takes real attention to detail. This project taught me that polish isn't superficial—it's what makes users trust a product. In enterprise software, where users are already skeptical of tech solutions, a well-designed interface builds confidence. Every color choice, every spacing decision, every animation serves the larger goal: make compliance feel manageable and professional.
